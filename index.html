SAEC BUS MAP

College bus information, made simple.

Bus movement is simulated from the timetable. It does not use live GPS tracking.

Source handling

Bus data in this demo is kept in data.js, separated from the UI so the timetable can be maintained without rewriting the interface.

The supplied PDFs provide morning stagewise timings. They do not provide a complete official evening stop-by-stop timetable, so the evening view is explicitly marked as a demo return mode rather than silently inventing an official schedule.
